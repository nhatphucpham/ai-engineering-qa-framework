## This session's executable design checks

- [Authority request specimens](ra1-design/request-specimens.json), [explicit read specimens](ra1-design/read-specimens.json) and their Draft2020-12 schemas check exact shapes/versions/fields/bounds and strict JSON/integer/unique-port wire rules only. They intentionally contain no live credentials. Well-shaped requests do not imply an allowed audience/current grant.
- [Pure corpus probe](ra1-design/corpus_probe.py) builds new authored bytes, checks source hashes/literal failure reasons/restricted aliases, calls existing projection/core and pure readside data functions through an explicit in-memory registry shim, and illustrates detached provenance/digest binding. It never instantiates Application/Store, dispatches an operation, starts a DB/worker or invokes reasoning. It does not prove authentication, serialized release, persistence or actual export.
- [Package verifier](ra1-design/verify.py) checks the full 833-path baseline with declared prefix/append exceptions, links, exact current source/payload pins and independently reviewed snapshot. Read-only default must compare against retained current manifest; exclusive capture never overwrites older checks. Source/protocol changes after a verdict require re-review and a new immutable capture.

Design DONE requires those actual limited checks PASS and independent latest-payload CLEAN; actual runtime matrix stays all NOT RUN. Implementation DONE later requires every I/A case actual PASS/CLEAN in scope. Full P4-D/P3-B/P4-E/P5/P6 remain OPEN, 7/12 and human pending.
