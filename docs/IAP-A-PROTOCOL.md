## Purpose, composition và non-goals

Kiểm common transaction-aware user identity/live policy/start/cancel/idempotency thay vì `Identity.check` trong transaction riêng rồi write qua boundary khác. Fresh `id_<uuid>` schema dùng nguyên S6-B identity tables/source/facade; thêm `application_identity=iap-a-1.0.0` và app tables, không migrate hoặc nối old S2/S6 namespaces. Tất cả identity và application writers dùng **cùng held control-row mutex** và DB clock; singleton serialization là tradeoff fixture, chưa throughput/runtime/production DB decision.

Queued-only model không có claim/worker/lease/dispatch/IO port; schema chỉ queued/cancelled và không có assignment. Vì construction này không thể launch work, queued cancel có thể terminal ngay. Không cho truyền `cleanup_ok=true`; không mô phỏng worker/container cleanup. S2 persistence source không được import như thể đã integrate worker lifecycle; report/core/publication semantics không sửa.

Outputs: protocol này; `spikes/iap/schema.sql`, `application.py`, `run_iap.py`, README; new `docs/iap-results/<fresh>.json`; results/review record `docs/IAP-A-RESULTS.md`; current plan/decision/handoff. Strict request `version=iap-a-1.0.0`, exact fields, no extra authority claims/unknown operation; trusted setup/fault hooks ngoài facade. Python host/DB trusted như S6-B, không introspection sandbox/network auth. Synthetic accounts/tokens/DB marker-bound only; không real keys/API/projects/global install/production stack.

## State/authority contract

- Reuse opaque user access/credential epoch/fixed live roles S6-B; không service credential accepted. App grant persisted subject+project+credentialEpoch+actions+policy epoch/configVersion+DB expiry/revoked. Grant actions ceiling không tăng sau promotion. Live role/project/account/session, app policy allowed actions/budget, grant subject/epoch và expiry được kiểm trong common transaction, **final conditional checkpoint** trước commit để expiry qua thời gian rollback.
- App policies khởi tạo bởi trusted harness; authenticated configure dùng S6-B `config` grant và live Owner/Admin, expected policy epoch CAS. Mọi policy update tăng epoch/configVersion, invalidate old app grants; widening cũng cần grant mới, immutable run snapshot giữ nguyên. S6-B membership changes không có membership epoch riêng; subset kiểm live role dưới mutex, chưa anti-rollback/member-lifecycle version provider tổng quát.
- Start bound exact candidate/input digest selector cùng project/config/policy version vào run và delegation metadata. Digests ở đây là caller-supplied synthetic snapshot selectors, **chưa trusted artifact resolver/assessment**; không claim content trust. Initiator từ authenticated DB principal. No user token persisted trong app state/delegation/receipt/audit/outbox.
- Unique command identity `(principal kind=user, principalId, project, operation, clientKey)`; digest là immutable comparison field. Canonical payload excludes bearer access và grant ID (authorization mỗi retry phải live), includes operation/project/command parameters/expected versions. Exact replay trả committed receipt sau current auth; changed payload conflict; same key different principal/project/operation là identity khác. DB mutex + unique PK bảo vệ two-process collision.
- Start atomic queued run + delegation metadata + immutable receipt + audit + initial outbox. Cancel Runner own/Owner/Admin permitted project, current cancel grant, expected version CAS; queued→cancelled + version+1 + receipt/audit/outbox. Unknown/cross-project ref cùng safe denial. Receipt query chỉ own principal+project+operation+key, current receipt grant/live read role, safe refs/status; replay start có thể trả historical queued receipt sau cancel, không giả current run state.
- Revoke app grant do same subject hoặc current Owner/Admin của project; chỉ authenticated boundary, unknown/cross-project deny. Snapshot revoke/reset/disable/project/policy narrowing chặn command tiếp theo. Queued delegation chỉ metadata, **chưa background authorization/dispatch**; logout/access expiry background continuation, worker enrollment/revoke, release permits/secret broker/content delivery đều NOT RUN.
- Admission budget max queued jobs theo project kiểm cùng transaction; fixture bound không SLA. Dependency policy missing/DB/audit failure fail closed. Success audit transactional; denial audit safe append sau rollback, chỉ fixed code/principal không raw request/token. Denial audit unavailable → dependency_unavailable; no accepted state. Database failure trả fixed dependency_unavailable, không raw exception qua facade. Trusted test hooks có thể gây actual deferred-FK commit failure; transaction phải rollback toàn graph.
