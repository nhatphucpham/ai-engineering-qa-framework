## Implementation contract before code

New `runtime_candidate/` is a synthetic application candidate, separate from old spikes and fixtures. No network listener binds publicly; test TLS uses disposable dummy certificates/pinned trust and loopback clients, never system trust installation. Only trusted bootstrap chooses DB schema/cache/cert and registers a fixed check/source snapshot; no public method accepts SQL, arbitrary path, shell command, bootstrap hook or dynamic dispatch name.

`common.py` owns finite canonical JSON, bounded strict parser and fixed error codes. `application.py` owns sessions/live project roles, configuration, intakes/run/lease/effect lifecycle and a fixed operation dispatch. Each HTTP request gets a fresh application/DB connection; all authorization/policy/assignment/publication mutations serialize via the existing identity transaction mutex and DB wall clock. Endpoint errors emit safe codes, no raw exception/path/credentials. No untrusted content changes check commands or grants itself approval.

`transport.py`: `serve(application_factory, certificate_path, key_path, *, host='127.0.0.1', port=0)` returns a bound HTTPS server; caller owns serving/shutdown. Factory returns an application with `dispatch(operation: str, token: str|None, body: dict)->dict` and `close()`. POST `/v1/<operation>` uses strict finite JSON object, Content-Length bound1MiB, exact one Bearer token when required; only session_login/session_refresh may omit token. Fixed operation allowlist. GET `/v1/events?project=<id>&run=<id>&after=<integer>` uses the same application `events` operation and produces standard id/event/data SSE records from persisted per-run outbox, with no credential in URLs. Each bounded release/reconnect rechecks current authorization; cursor ahead/gap rejects explicitly with a safe resync-required code, while run_read returns an atomic run snapshot with sequence watermark. Never share a cursor across same-project sibling runs. Standard-library TLS/HTTP is candidate infrastructure, not a new production-framework choice.

The exact request/response/role/version/error contract is [candidate API1.1.0](../runtime_candidate/API.md). Its private factory `release_unit(operation,token,body,result)` context manager holds live authority ordering through each actual at-most4KiB ordinary-content write (at most64KiB total), including SSE record boundaries; unknown/missing hook denies before response. Revocation after generation stops the next release unit; admitted bounded bytes are irreversible. Resource authorization errors are generic and do not distinguish nonexistent from cross-scope objects. Version and route allowlist consistency are required conformance checks.

`blobs.py`: marker-bound directory chosen only at trusted bootstrap; immutable SHA256-addressed byte objects, bounded writes, no-follow containment, exact read hash/length; ambiguous existing bytes reject, same bytes idempotent, partial stage never ordinary content.
